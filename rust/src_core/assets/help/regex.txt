Option -P enables Perl regex matching with Unicode patterns, lookarounds and
capturing groups.

Option -U disables full Unicode pattern matching: non-POSIX Unicode character
classes \p{class} are disabled, ASCII, LATIN1 and binary regex patterns only.

To match multiple lines, specify a pattern that matches line breaks, such as
\n or \R.  Character classes do not match a newline character, except for
\P, \D, \H, \W and \X and when a \n or a \R is explicitly specified,
such as [\s\n].

Options -% (--bool --lines) and -%% (--bool --files) augments pattern syntax:

 pattern     operation                   pattern     operation
 ----------  --------------------------  ----------  --------------------------
 (...)       grouping                    "..."       the literal string ...
 -a          logical not a               NOT a       locical not a
 a|b         logical a or b              a OR b      logical a or b
 a b         logical a and b             a AND b     locical a and b
 --------------------------------------  --------------------------------------

Listed from the highest level of precedence to the lowest, NOT is performed
before OR and OR is performed before AND.  Thus, `-x|y z' is `((-x)|y) z'.
Spacing of the logical AND, OR and NOT operators is required.

Nested parentheses that are part of a regex sub-pattern do not group logical
operators.  For example, `((x y)z)' matches `x yz'.  Note that `((x y){3} z)'
matches `x y' three times and a `z', since the outer parentheses group the AND
(a space).

Option -% matches lines satisfying the Boolean query.  The double short option
-%% matches files satisfying the Boolean query.

See also options --and, --andnot, --not to specify sub-patterns as command-line
arguments with these options as logical operators and option -e as logical OR.

Option --stats displays the options and patterns applied to the matching files.

NOTE: always quote regex patterns to prevent the shell from expanding globs.
NOTE: a pattern starting with a `-' requires option -e as in -e '-PATTERN'.
